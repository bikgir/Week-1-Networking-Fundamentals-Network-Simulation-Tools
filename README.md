# **Week-1**

**Introduction**

Computer networks allow devices to exchange data and share resources through wired or wireless
communication links. Understanding how devices are connected, how IP addresses are assigned, and
how connectivity is verified is a core foundation of networking and network administration.
This practical exercise uses Cisco Packet Tracer, a network simulation and learning application, to
explore a basic network topology and verify communication between devices. The supplied
screenshots show the Packet Tracer logical workspace and a command-prompt test in which a laptop
configured with IPv4 address 192.168.0.2 successfully pings the destination 192.168.0.3.
The report documents the network concepts demonstrated, describes the Packet Tracer interface and
visible topology, explains the IP configuration, and interprets the connectivity test results.
